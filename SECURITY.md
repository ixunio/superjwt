# Security Policy

## Reporting a Vulnerability
If you think you have identified a security issue in SuperJWT, do not open a public issue.

To responsibly report a security issue, please navigate to the 'Security' tab within the GitHub repository and click 'Report a vulnerability'.

Please include as much detail as possible. Just like reporting standard issues, providing a minimal reproducible example will help maintainers address the vulnerability faster.

Thank you!

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| ≥ 0.7   | :white_check_mark: |
| ≤ 0.6   | :x:                |
